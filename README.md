# 13 — לוח ניקוד

אפליקציית web לעקוב אחרי נקודות במשחק הקלפים "13" (וריאציית הכרזות של ויסט).

## איך זה עובד

- 4 שחקנים
- 13 סיבובים: בסיבוב N מחלקים N קלפים לכל שחקן (1, 2, 3, ... 13)
- בכל סיבוב יש שני שלבים:
  1. **הכרזות** — כל שחקן מצהיר כמה לקיחות הוא חושב שייקח
  2. **תוצאות** — מזינים כמה לקיחות כל אחד באמת לקח
- **ניקוד**: שחקן שעמד בהכרזה מקבל `10 + הכרזה²`. שחקן שלא עמד — 0.
- **כלל המחלק**: סכום ההכרזות לא יכול להיות שווה למספר הקלפים בסיבוב (כך שלפחות שחקן אחד חייב להיכשל). האפליקציה מציגה למחלק איזה מספר אסור לו להכריז ולא תאפשר להמשיך אם הסכום שווה לאסור.
- המחלק מתחלף בכל סיבוב לפי הסדר.

## הפעלה מקומית

פשוט לפתוח את `index.html` בדפדפן. אין צורך ב-build / npm / שרת.

## העלאה ל-GitHub Pages

```bash
# יצירת ריפו חדש
git init
git add index.html README.md
git commit -m "Initial commit"

# יצירת ריפו ב-GitHub (למשל בשם thirteen-app), ואז:
git remote add origin https://github.com/YOUR_USERNAME/thirteen-app.git
git branch -M main
git push -u origin main
```

לאחר מכן ב-GitHub:
1. עוברים ל-**Settings → Pages**
2. תחת **Source** בוחרים `Deploy from a branch`
3. בוחרים branch `main` ותיקייה `/ (root)`
4. שומרים — תוך כמה דקות האתר יהיה זמין ב-`https://YOUR_USERNAME.github.io/thirteen-app/`

## תכונות

- ✅ שמירה אוטומטית ב-localStorage — אפשר לסגור את הדפדפן ולחזור
- ✅ כפתור "בטל סיבוב" אם טעיתם
- ✅ הצגת אזהרה ברורה למחלק על המספר האסור
- ✅ טבלת היסטוריה עם הכרזה/לקיחה/ניקוד לכל סיבוב
- ✅ הכרזת מנצח בסוף המשחק
- ✅ עיצוב מותאם למובייל וגם לדסקטופ
- ✅ הכל בעברית עם RTL
